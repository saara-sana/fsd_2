How It Works

Built with plain HTML, CSS and JavaScript — no frameworks, no backend, no database.

01

Pick a Subject

Choose from 6 topics. Each quiz pulls 10 questions at random so it feels different every time.

02

Answer in Time

30 seconds per question. Answering faster gives you more bonus points on top of the base score.

03

Review Your Results

After the last question, you get a grade and a full breakdown — every question, right or wrong, with a short explanation.

What's inside

Timer

30s countdown using setInterval. Turns red under 10s.

Instant Feedback

Correct/wrong highlighted immediately with an explanation.

Randomised Questions

Questions shuffled each round using sort + Math.random.

Score Breakdown

End screen shows every answer so you can learn from mistakes.

Responsive Design

CSS Grid + media queries. Works on mobile and desktop.

60 Questions

10 per subject, all written by hand. No API, no external data.
